# Teste técnico — Automação web com Cypress (2022)

Projeto desenvolvido como teste técnico em um processo seletivo para QA,
no qual fui aprovada. Feito sem uso de ferramentas de IA.

O que o projeto cobre:
- Testes E2E da aplicação fotos
- Relatórios HTML com Mochawesome

Observação: o site testado era hospedado no Heroku e não está mais no ar,
por isso os testes não rodam hoje. O código está mantido como registro
do teste original.

Hoje trabalho como QA Engineer II no setor financeiro, com foco em
automação e testes de API (Python, Pytest, C#).
