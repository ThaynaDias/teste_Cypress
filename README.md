# Automação web com Cypress — projeto de estudo (2022)

Projeto que desenvolvi para estudar automação de testes com Cypress
e me preparar para o teste técnico do processo seletivo da minha
vaga atual de QA, no qual fui aprovada. Feito sem uso de ferramentas de IA.

O que o projeto cobre:
- Testes E2E de uma aplicação web de fotos
- Relatórios HTML com Mochawesome

Observação: o site testado era hospedado no Heroku e não está mais no ar,
por isso os testes não rodam hoje. O código está mantido como registro
dos meus estudos.

Hoje sou QA Engineer II no setor financeiro, com foco em automação e
testes de API (Python, Pytest, C#).
